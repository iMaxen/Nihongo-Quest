A free, open-source Japanese learning platform built to take you from your first kana to advanced Japanese proficiency.

Nihongo Quest is a Japanese language learning application designed around structured progression, spaced repetition, and immersive practice. It combines an engaging, Duolingo-inspired user interface with a more rigorous approach to learning Japanese, helping learners build their knowledge gradually and develop the skills needed for real-world comprehension.

The project is built around a simple idea: learning a language should be engaging enough to keep you coming back, while remaining substantial enough to help you make genuine progress.

Whether you're starting with hiragana and katakana, working through Japanese grammar, expanding your vocabulary, or pushing towards advanced proficiency, Nihongo Quest is designed to support your journey.
About the Project
Nihongo Quest is more than a collection of vocabulary exercises. It is designed as a structured learning environment where lessons, reviews, and contextual interactions work together to reinforce what you learn.

The platform takes inspiration from the accessible, progression-driven experience of Duolingo while placing particular emphasis on Japanese language development. Its learning experience is designed to encourage consistency without sacrificing depth.

The project also prioritises user privacy and accessibility. It is free to use, open source, and designed without advertisements or telemetry.
Features
Structured Japanese Curriculum
Nihongo Quest organises learning into a progressive course, allowing learners to develop their understanding of Japanese step by step.

Lessons are designed to introduce and reinforce concepts within a broader learning path rather than treating each exercise as an isolated activity. This provides a foundation for continued study as learners advance through increasingly demanding material.

The curriculum aims to support development across Japanese vocabulary, grammar, reading comprehension, and contextual understanding.
Spaced Repetition System
Remembering Japanese requires more than encountering a word once. Nihongo Quest incorporates a spaced repetition system (SRS) to support long-term retention through review.

The system helps learners revisit previously encountered material instead of relying entirely on new lessons. This makes revision an integral part of the learning experience and helps reinforce knowledge over time.
Immersive Learning Interactions
Learning a language becomes more meaningful when words and grammatical structures appear in context.

Nihongo Quest features hundreds of handcrafted interactions and pieces of dialogue designed to make learning more engaging. These interactions help give the course personality while providing opportunities to encounter Japanese in contextual situations.

The project aims to make practice feel like part of a larger learning journey rather than an endless sequence of disconnected questions.
A Duolingo-Inspired Interface
Nihongo Quest uses a user interface inspired by the accessible, interactive design of modern language-learning applications, particularly Duolingo.

The interface is designed to make lessons approachable and progression easy to follow. Its presentation supports the learning experience without making the application feel like a conventional textbook.

The goal is to combine an inviting interface with meaningful educational content, keeping the experience approachable for beginners while supporting more ambitious learners.
Aiming for Advanced Proficiency
Nihongo Quest is designed with long-term Japanese learning in mind.

Rather than focusing exclusively on introductory phrases, the project aims to support progression towards advanced proficiency, including the knowledge needed to work towards JLPT N2 and N1-level Japanese.

These levels represent ambitious learning goals, and actual proficiency depends on the learner's practice, comprehension, and ability to use Japanese beyond the application.
Local Save Data
Nihongo Quest supports local, text-file-based save data, allowing learning progress to be stored locally.

This approach aligns with the project's emphasis on user control and transparency. It also avoids making a remote account system a prerequisite for the local learning experience.
Privacy and Open Source
Nihongo Quest is designed to be a straightforward learning tool without unnecessary tracking.
- No advertisements.
- No telemetry.
- Local save data.
- Open-source development.
- Free access to the learning experience.
The project aims to keep the focus on learning Japanese rather than monetisation, engagement tracking, or collecting unnecessary user information.
Design Philosophy
Nihongo Quest is built around the belief that an effective learning application should balance usability with educational substance.

Engagement should support learning. An enjoyable interface can help make regular practice easier to maintain, but the underlying course must still provide meaningful material.

Progress should be deliberate. Learning Japanese involves accumulating knowledge over time. Lessons and reviews should contribute to a broader understanding of the language.

The learner should remain in control. Local save data, an open-source codebase, and an absence of telemetry reflect a commitment to transparency and user autonomy.

Advanced learning deserves attention. Japanese education should not stop at beginner-level vocabulary and familiar phrases. Nihongo Quest is intended to support a longer journey towards independent comprehension.
Who Is Nihongo Quest For?
Nihongo Quest is intended for learners who want a structured way to study Japanese and build their knowledge over time.

It may be particularly useful for:
- Beginners learning hiragana, katakana, and foundational Japanese.
- Learners who want regular vocabulary and grammar practice.
- Students looking for a more structured approach to Japanese study.
- Independent learners working towards JLPT proficiency.
- Japanese enthusiasts who want a dedicated learning environment they can use consistently.
No single application can replace every aspect of language acquisition. Nihongo Quest is intended to serve as a substantial learning resource that can complement reading, listening, conversation, and other forms of immersion.
